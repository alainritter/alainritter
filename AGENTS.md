# AGENTS.md

GitHub profile repo `alainritter/alainritter`: `README.md` is the public profile page. There is no build or test setup.

- Text in English, no emojis.
- `assets/` holds the banner SVGs (light and dark) referenced by the README; `github-metrics.svg` is generated by the workflow in `.github/workflows/`, do not edit it by hand.
- `city/` generates the repo city (one building per repo, animated SVG + Three.js page in `city/site/`). The workflow `city.yml` runs it daily and publishes to the branch `city` (not `output`: the snake workflow wipes that one). Private repos are reduced to anonymous fields in `city/sanitize.mjs`, and `city/gate.mjs` aborts the build if a private name (4+ characters) appears in any output file. Do not weaken either. Tests: `node --test "city/*.test.mjs"`. Local build: `GH_TOKEN=$(gh auth token) OUT_DIR=/tmp/city node city/build.mjs`. One-time setup after the first workflow run: enable Pages with source branch `city` (`gh api -X POST repos/alainritter/alainritter/pages -f "source[branch]=city" -f "source[path]=/"`); until then the README images and 3D link are broken.
- Project entries in "Selected work" must match the current state of those projects (name, link, one-line description).
